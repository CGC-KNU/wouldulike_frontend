## 식당별 링크

특정 매장은 기존과 같습니다. `id`만 바꿉니다.

https://cgc-knu.github.io/wouldulike_deeplink/?type=restaurant&id=56

리스트만 열려면 `id`를 빼거나 `type=restaurants`를 씁니다.

## 브릿지 동작

- 앱 안 배너·기획전 링크는 HTTPS를 브라우저로 보내지 않고 앱이 바로 해석합니다. 위 type은 이 앱 빌드에서 동작합니다.
- 카카오·문자·사파리에서 열면 [브릿지 페이지](https://cgc-knu.github.io/wouldulike_deeplink/?type=restaurant&id=56) HTML이 `wouldulike://`로 넘깁니다. 2026-09-13 기준 배포 HTML은 `restaurant` / `restaurants` / `affiliate` / `tab` / `coupons` / `coupon` / `main` / `mileage`(쿠폰함으로 보냄)만 알고 있습니다. `stamps`, `shop`, `mission` 등을 밖에서 열려면 브릿지 HTML에도 같은 type을 추가해야 합니다.

## 주의

- PIN 입력, 쿠폰 발급 팝업, 추천인 코드 시트, OS 알림 설정, 카카오 1:1 문의, 사장님 대시보드는 딥링크 대상이 아닙니다.
- `type=mileage`는 이제 지갑의 **마일리지 탭**입니다. 쿠폰 탭으로 보내려면 `type=coupons`, 상점까지 가려면 `type=shop`입니다.
